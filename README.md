# Carnet de forme

Un carnet de suivi quotidien à installer sur son téléphone : poids, repas (avec photos), activité, eau, sommeil, ressenti, mensurations, programme calculé et analyse des tendances.

**Ouvrir l'application :** https://zakaria-mzl.github.io/carnet-de-forme/

## Vos données restent chez vous

Ce dépôt ne contient que le code de l'application. Tout ce que vous saisissez reste dans le stockage de votre propre navigateur, sur votre téléphone. Rien n'est envoyé ici ni ailleurs, et personne d'autre ne peut le voir.

Pensez à faire de temps en temps **Profil → Exporter mes données** : le fichier obtenu sert de sauvegarde et permet de passer sur un autre téléphone.

## Installer sur le téléphone

- **iPhone** : ouvrir le lien dans Safari → bouton Partager → « Sur l'écran d'accueil ».
- **Android** : ouvrir le lien dans Chrome → menu ⋮ → « Installer l'application ».

Une fois installée, l'application fonctionne aussi sans connexion.

---

Les calculs (dépense, protéines, programme) s'appuient sur des formules reconnues et ne remplacent pas l'avis d'un médecin ou d'un diététicien.
